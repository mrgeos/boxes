# Box Studio 3D

Редактор 3D-мокапов упаковки в одном HTML-файле. Откройте `box-studio-3d.html` в Chrome, Safari или Firefox. Three.js встроен в файл, поэтому редактор работает без интернета. Без сети веб-шрифты заменяются системными.

Это развитие «Студии коробки» (исходная версия лежит в `legacy/studiya-korobki-original.html`). Её проекты (`box-mockup-project.json`) открываются кнопкой «Открыть…».

## Что умеет

- **Модели:** коробка, бумажный стакан, пакет и тубус/банка. Размеры в мм, толщина картона, несколько объектов в одной сцене. Заготовки: коробка с окном, коробки с клапаном 150×90×70 и 230×140×60 (в т. ч. с окном в крышке), мейлер, крышка-дно, коробки для торта с прозрачной крышкой (белая и крафт), лоток, гофрокороб, коробка для продукта, подарочная, плоская.
- **Бумажные стаканы:** 250, 350 и 450 мл (⌀ верха/дна и высота настраиваются). Двухслойные (внешний слой не доходит до дна, снизу видна полоска внутреннего стакана) или однослойные. Пластиковая крышка с поилкой — чёрная, белая или любого цвета, её можно снять ползунком. Дизайн стенки рисуется на прямоугольнике и ложится на конус без искажения пропорций (к широкому верху элементы крупнее). Для типографии шаблон SVG и PNG выгружаются «веером» — точной развёрткой конуса с нахлёстом 8 мм на шве.
- **Пакеты:** плоский (например, под одно печенье, 140×140) или с плоским дном, как для кофе (90×60×230). Верх: клапан с клеевой лентой (её видно, если открыть клапан ползунком), отворот или скрутка в 2–3 оборота (плотный валик сверху), запайка или открытая горловина (мягко приоткрыта, степень раскрытия задаётся ползунком от почти сомкнутой до прямой трубы, по желанию с зубчатым краем — например, чтобы из пакета торчал багет; заготовка «Пакет для багета 100×450»). У пакета с дном верх «домиком»: перед и зад сходятся по чётким сгибам, фальцы складываются внутрь треугольниками; высота ската — авто или ползунком. В бумажных и крафт-пакетах можно вырезать окно с плёнкой на переде: оно растёт от своего центра (центр задаётся высотой от дна и сдвигом вбок), углы прямые или скруглённые. Материал: прозрачная плёнка, матовая (frosty), калька, белая бумага, крафт; на плёнке всё, что не запечатано, остаётся прозрачным или полупрозрачным, видны запаянные швы. Плоский пакет раздут содержимым. Внутрь можно поставить фото продукта без фона (PNG) — за матовой плёнкой и калькой оно размыто. Экстендер — картонный хедер, согнутый через верх и прибитый скобами, с печатью с двух сторон; «нахлёст на пакет» задаёт, насколько пакет заходит в хедер: остальная часть хедера поднимается над пакетом, скобы идут по центру нахлёста. Наклейки ложатся на мягкую форму и переходят через сгиб (клапан или отворот → перед, экстендер → пакет). Развёртка и шаблон SVG: рез, сгибы, запайка, клеевой шов и лента клапана.
- **Стенки дна:** толщина настраивается отдельно от картона; толще картона — двойной борт со сгибом сверху (на развёртке появляются внутренние борта).
- **Типы крышек:** откидная; откидная с клапаном снаружи (крышка шире и глубже основания на толщину картона, клапан и боковые ушки всегда снаружи; ушки по умолчанию на всю глубину коробки, длину можно задать вручную); откидная с клапаном внутрь (мейлер); отдельная крышка-дно (высота крышки настраивается; крышка может быть из прозрачного ПЭТ — как у коробки для торта: печать на прозрачных гранях, посадка поверх дна или внутри дна, когда лоток обхватывает крышку); без крышки (лоток). Крышку можно открыть или поднять ползунком. У клапана, ушек и стенок крышки-дна — свои грани для дизайна.
- **Дизайн по граням:** у каждой грани свой фон и слои: картинки, текст, плашки, круги. Слой можно двигать, масштабировать и поворачивать в 2D-окне грани или тянуть прямо по 3D-модели. Есть привязка к центру и краям.
- **Окно с плёнкой:** на любой коробке с крышкой. Через переднее ребро: с крышки на переднюю стенку или, у коробки с клапаном, на клапан (стенка за клапаном прорезается тоже). Через заднее ребро: с крышки на заднюю стенку, через линию сгиба крышки (у откидных крышек, включая клапан и мейлер). Или закрытое окно в крышке со сдвигом вперёд/назад. Углы скруглённые или прямые; размеры и радиус настраиваются. Окно видно в окне грани, на развёртке и в шаблоне SVG (биговки прерываются в окне).
- **Выбор цвета:** клик по любому цветовому полю открывает панель «Цвета в документе» (все цвета, уже использованные в объектах: картон, фоны граней, слои, наклейки, крышки, по частоте) и «Последние использованные» (запоминаются в браузере, до 12). Есть пипетка (в Chrome и Edge) и кнопка «Другой цвет…» для обычного выбора.
- **Цвет картона:** палитра (белый, крафт, графит, шалфей, розовый, голубой) или свой цвет, плюс переключатель «Белая внутренняя сторона».
- **Узор:** картинку можно повторять плиткой по всей грани.
- **Наклейки:** круг/овал, прямоугольник со скруглением или своя форма из PNG/SVG с прозрачным фоном (с белой окантовкой). Размер и толщина в мм (от тонкой бумаги до толстого винила — видна кромка), фон или «без фона», обводка, логотип, текст, покрытие (глянец, мат, фольга, голография, прозрачная плёнка), мягкая тень. Наклейка — отдельная плёнка поверх коробки: на перепаде высот (край клапана, крышки) и во внутренних углах она не повторяет ступеньку, а перекидывается через неё; насколько — задаёт «Натяжение плёнки» (0 % — плотно облегает, 100 % — натянута, скругление до 15 мм). Наклейку тянут мышью по модели: она переходит через рёбра — наружные и внутренние, цепочкой через несколько поверхностей (например, с прозрачной крышки торта через верх борта на стенку лотка), с клапана — на стенку под ним, с крышки-дна — на лоток. Кнопка «Пломба» ставит полоску на линию открытия; при открытии части расходятся. В печатную развёртку наклейки не попадают.
- **Внутренняя печать:** отдельные грани «Крышка изнутри» и «Дно изнутри».
- **Отделка слоёв:** фольга (золото, серебро, медь, голография), выборочный УФ-лак, тиснение, конгрев.
- **Покрытия:** матовый картон, soft-touch, глянцевая ламинация, крафт (печать по бурому картону), металлизированный картон. Есть фактура бумаги.
- **Развёртка:** шаблон SVG в мм (линии реза и биговки). Крышка с клапаном и ушками лежит одной деталью, прикреплённой к задней стенке, как на штанцформе (повёрнута на 180°). Готовый макет всей развёртки можно загрузить целиком: он разрежется по граням. Есть экспорт развёртки с дизайном в PNG.
- **Подсказка о печати:** для картинок показывается dpi при печати в текущем размере.
- **Экспорт:** PNG 1×–4× (с прозрачным фоном или без), видео 360° (WebM).
- **Проект:** автосохранение в браузере, сохранение/открытие `.boxstudio.json` (картинки и шрифты внутри файла), отмена/повтор, свои шрифты (TTF/OTF/WOFF).

## Управление

| Действие | Как |
|---|---|
| Вращать камеру | левая кнопка; при включённом «◎ Вокруг выбранного» — вокруг выбранного объекта |
| Сдвинуть вид | правая кнопка, Shift/Ctrl + левая или два пальца; центр вращения остаётся на объекте |
| Масштаб | колесо или щипок, к выбранному объекту |
| Приблизить объект / вся сцена | двойной клик или F / H |
| Выбрать грань | клик по модели, по вкладке грани или по панели развёртки |
| Двигать слой на модели | выбрать слой, затем тянуть его мышью по 3D |
| Двигать наклейку | выбрать наклейку кликом, затем тянуть по модели (через рёбра тоже); стрелки — точный сдвиг |
| Добавить картинку | кнопка «Картинка», перетаскивание файла на грань или Ctrl+V |
| Сдвиг слоя | стрелки (Shift — шаг крупнее) |
| Удалить / дублировать слой | Delete / Ctrl+D |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z |
| Без привязок при перетаскивании | держать Alt |

## Разработка

Исходник — `src/box-studio-3d.html` (подключает three.js с CDN, удобно править). Автономный файл собирается так:

```
npm install
npm run build
```

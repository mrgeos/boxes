# Коробка-книжка сборная (плоская в доставке) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** у коробки-книжки на магните есть вариант «Сборная»: стенки лотка — картон в той же обтяжке, что переплёт, на бумажных шарнирах от дна; едет плоским крестом, собирается поднятием стенок и ушками на двустороннем скотче; в «Сборке» видно, как крест складывается в коробку.

**Architecture:** не новый тип крышки, а флаг `o.bookFlat` у `lidType: 'book'` — грани, размеры граней, тишью, окно, группа в панели уже ветвятся по `'book'` и продолжают работать. Отличаются три места: размеры (`bookDims`: стенки во всю ширину, без отступа), развёртка (`bookFlatNet` — один лист вместо двух) и сборка (семейство `bookFold` в `fold-rig.js`). 3D модели почти не меняется: тот же переплёт и те же стенки, только дно короче на толщину клапана и стенки заподлицо с краями.

**Tech Stack:** Three.js, ES-модули `src/app`, сборка `npm run build`, e2e на Playwright (`npm run prepush`).

**Spec:** нет отдельного документа — исследование в разговоре (2026-11-14) и решения ниже. Основа в коде: `carriers/book.js` (`bookDims`, `buildBook`, `bookNet`), образец семейства сборки — `casketFold` и `mailerFold` (`carriers/fold-rig.js`, `carriers/mailer.js`), правила печати клапанов — `net/flap-rules.js`.

## Как устроена настоящая (решения автора плана — проверить на ревью)
- Переплётный картон 1,5–2 мм, обтяжка 120–157 г/м² — одним листом на всё: дно, корешок, крышка, клапан **и** три стенки лотка (перед, левый, правый бок). Задняя стенка лотка — сам корешок.
- Шарниры — зазоры в картоне шириной `2t + 1` мм под бумагой (как уже между дном, корешком и крышкой в `bookNet`).
- У боковых стенок по два ушка (к передней стенке и к корешку), на ушках двусторонний скотч с защитной лентой; ушки клеятся изнутри. Сборка однократная.
- Магниты в клапане и передней стенке — не моделируем (у обычной книжки тоже не моделированы).
- Вкладыш (бумага внутри поверх ушек) — не на развёртке, как у обычной книжки (там дно лотка тоже без печати).

2. **Переключение флага у коробки с дизайном**: слои на гранях `left`, `right`, `trayFront`, `top` остаются (набор граней тот же) — пункт 1, шаг «переключение».
3. **Тишью и толщина у сборной**: `tissue.js` берёт `bookDims`; с `ov = 0` бумага не вылезает за стенки. Пункт 1, шаг «тишью».
4. **Ушки без печати**: на PNG/PDF развёртки ушки — цвет листа, печать только полосой `glueBleed` у сгиба (правило клеевых клапанов). Пункт 2.
5. **Крышка в «Сборке» на 100 %** открывается так же, как у модели (ползунок крышки двигает и каркас) — пункт 3.

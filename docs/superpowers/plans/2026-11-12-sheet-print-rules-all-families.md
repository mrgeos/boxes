# Правила печати листа для всех упаковок из листа — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** то, что уже работает у коробки с ручкой (печать на клапанах, полоса печати на клеевом клапане, зона клея без краски и лака), работает у всех упаковок из листа: в 2D, PNG, PDF и 3D.

**Решения автора:** «так должны работать все упаковки из листового материала»; вылет печати на клеевой клапан — по практике типографий (по умолчанию 3 мм, настраивается), дальше зона клея без краски и лака. ПЭТ-крышки по умолчанию прозрачные — печать на них остаётся опцией, в этот план не входит.

**Основа (уже есть):** `faces/flaps.js` (`drawFlap`, `flapRect`, `bareRect`, `ensureFlaps`, `renderFlaps`), панели с `flap: { bgOf, strip? }` и `glueStrip`, потребители в `net/net-view.js`, `net/template.js` (`printCanvas`), `export/pdf.js`, `net/bleed.js`, `carriers/fold-rig.js` (`p.flap` → текстура `rt.flaps`), образец — `carriers/handle-box.js` (`hbNet`, `buildHandleBox`).

## Опись (скрипт `scratchpad/checks/inventory.mjs`, на основной ветке после #51)
- Панели без печати (`blank`, без грани): мейлер `f0427` — `dust` ×2, `ear` ×4; гофрокороб `f0201` — `iflap` ×4; домик `gable` — `bflap`; книжка `book` — `tbottom`, `tback`; футляр с ящиком `drawer` — `dbottom`, `dback`, `dleft`, `dright`; бумажный пакет `paperbag` — `turn`, `base`, `glue`; пакеты `bag` (с дном) — `hidden` ×4, `glue`.
- Язычки `n.tabs` (рисуются цветом картона, без вылета): почти у всех коробок, 1–8 на заготовку (коробки с клапаном, крышка-дно, пачки ECMA, шкатулка, книжка, футляр, подушка, домик, шестигранник, лотки).
- Зоны клея на панели (`p.glue`): рукав, рукав-переноска тортницы.

## Правила (для строителя — как классифицировать)
1. **Клеевой клапан** (боковой шов, клеевые уголки лотка-креста, клеевой клапан пакета): полоса печати от сгиба шириной `o.glueBleed` (мм, по умолчанию 3, 0–10), остальное — зона клея без краски и лака; вылет соседней панели в неё не заходит (как `glueStrip` у коробки с ручкой).
2. **Загибы обтяжки жёстких коробок** (шкатулка, книжка, футляр, крышка-дно с обтяжкой — где бумага обтягивает картон и загибы видны внутри): печатаются целиком, фон — грань, с которой загиб уходит.
3. **Остальные несущие панели без своей грани** (пылевые клапаны, ушки, внутренние клапаны, клапаны дна, отворот и дно пакета, язычки замков): печатаются целиком — фон грани, на которой висят (по сгибу), плюс слои «Развёртки».
4. Скрытые складки, которые внутри и не видны (`hidden` у пакетов): тоже печатаются по правилу 3 — офсет печатает весь лист; если строитель видит причину иначе (например, это не деталь листа) — оставить и записать.
- Как определить, на какой грани висит клапан: по сгибу (общий край с панелью, у которой есть грань; `dieLines` / `joins` / `on` у язычков). Делать это одним общим способом (одна функция над `n.panels`/`n.tabs`), а не вручную в каждом семействе, где это возможно.

## Global Constraints
- Правила `CLAUDE.md`; новых тестов не добавлять (тест «все заготовки» проверяет построение, шаблоны SVG/DXF и `foldDrift`); не добавлять новых чипов граней.
- `o.glueBleed` — общая настройка вместо `o.hbEnd.glue` у коробки с ручкой (старые проекты переносить не нужно); поле «Вылет на клеевой клапан, мм» в панели «Форма» у всех упаковок, где есть клеевой клапан.
- 2D, PNG, PDF и 3D должны совпадать. Если для какого-то семейства обновить 3D дороже ~60 строк — сделать 2D и печать, а в `PLAN.md` записать, что в 3D у этого семейства клапаны пока цвета картона.
- Снимки 3D на этой машине не повторяются байт в байт — смотреть глазами; SVG-шаблоны сравнивать можно.

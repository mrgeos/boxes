# Печать на клапанах в 3D (остаток) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** в 3D основной модели видны те клапаны, которые видно у настоящей коробки, с той же печатью, что в 2D/PNG/PDF; плюс одна правка печати (клеевой треугольник дна-автомата).

**Основа:** `net/flap-rules.js` (`applyFlapRules`, `printPanels`, панели и «двойники» язычков с `flap`/`glueStrip`), `faces/flaps.js` (`drawFlap`, `ensureFlaps`, `renderFlaps`, текстура `rt.flaps`, UV по листу), образцы 3D: `carriers/mailer.js` (пылевые клапаны мейлера), `carriers/rsc.js` (внутренние клапаны гофрокороба), `buildHandleBox` (`carriers/handle-box.js`). Записи в `PLAN.md`, раздел «3D: печать на клапанах (остаток после правил листа)».

## Global Constraints
- Правила `CLAUDE.md`; новых тестов не добавлять (тест «все заготовки» проверяет построение, шаблоны и `foldDrift` ≤ 0,5 мм — новые меши не должны её сломать).
- Новые меши берут картинку только из `rt.flaps` (один источник с 2D/печатью); зона клея на них — цвет картона (как сейчас в `renderFlaps`).
- Строить только то, что видно у настоящей коробки (решение автора: «так, как в жизни»); спрятанное между слоями стенок — не строить.
- Если пункт дороже ~80 строк — сделать остальные, этот записать в `PLAN.md` с причиной.
- Снимки 3D на этой машине не повторяются байт в байт — смотреть глазами.

## Tasks (по порядку, коммит после каждого: `Клапаны в 3D: <что>`)
1. **Клеевой треугольник дна-автомата** (`cartonCrash`): зона `t.glue` у язычка — без печати, как полоса клеевого клапана (2D, PNG, PDF, 3D/«Сборка»). Проверка пикселями PNG: внутри треугольника прозрачно, рядом — цвет клапана.
2. **Пылевые клапаны пачек ECMA** (`cartonRTE`, `cartonSTE`, `cartonCrash`, `cartonSnap`, `product`): верхние (и где видно — нижние) пылевые клапаны как меши с печатью; видны при открытой крышке. Открытие пылевых клапанов вместе с крышкой — по образцу торца коробки с ручкой (`applyLid`), если у модели пачки крышка открывается.
3. **Клеевые уголки лотка-креста** (`boxFold`: крышка-дно `lidbase`/`gift`/`boxBand`, лоток `tray`, `matchbox`, коробки `flat`/`flap`/`tuck` с лотком-крестом): уголки внутри углов как меши — полоса печати `glueBleed` у сгиба, дальше картон.
4. **Загибы обтяжки жёстких коробок** (`casket`, `book*`, `drawerBox`): полоса загиба по верху стенок изнутри (и где видно у крышки) с печатью грани, с которой загиб уходит.
5. **Отворот бумажного пакета** (`paperBagKraft`, `paperBagWhite`): отворот внутри по верхнему краю с печатью.
6. **Язычок коробки с ручкой** (`buildHandleBox`): печать как у верхнего клапана торца.
- После каждого пункта: снимок 3D с открытой крышкой/торцом (скрипт в `scratchpad/checks/`), `drift.mjs`.
- В конце: README (абзац про печать на клапанах — что видно в 3D), `PLAN.md` (сделанное — в «Сделано», остаток с причинами), `npm run build`, `PW_CHROMIUM=… npm run prepush`.

# 3D из кроя, фаза 3: «Сборка» коробки для торта с ручкой — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** коробка для торта с ручкой (`lidType: 'handle'`) складывается ползунком «Сборка» из своего кроя, проходит сверку `foldDrift` (≤ 0,5 мм) и в конце сборки без рывка открывает торец, как модель.

**Architecture:** новое семейство складывания `handleFold` в `carriers/fold-rig.js` (как `boxFold`, `cartonFold`) поверх кроя `hbNet` (`carriers/handle-box.js`). Лепестки ручки вырублены из крышки и поднимаются по сгибам у перемычки — их каркас добавляет к панели крышки отдельно, потому что в `hbNet` они не панели полосы, а `leaves` (контуры на крышке) и `part`-детали. Подложка (`tray`) — отдельная деталь: в каркас не входит и появляется с моделью на 100 % (как допы, решение фазы 2).

**Tech Stack:** ES-модули, three.js, Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-10-product-source-of-truth-design.md` (3.1, 6.1 шаг 4: «затем семейства, которые сейчас не складываются, начиная с коробки с ручкой»). Предыдущая фаза: `docs/superpowers/plans/2026-11-10-fold-matches-model.md` (сверка `foldDrift`, открытие крышки в конце сборки).

## Факты о крое (`hbNet`, `handle-box.js`)

- Полоса сверху вниз: `front` (y 0…h) — `top` (h…h+d) — `back` — `bottom` — `glue` (клеевой клапан 12 мм). Лист виден снаружи: правая сторона коробки (+x) на листе слева.
- Открытый торец (`hbOpen`, по умолчанию правый): `rightTop` на боку `top`, `rightBottom` на боку `bottom` (по `half = h/2` шириной), клапаны `dust` на боках `front` и `back`; язычок (`tabs`) на свободном крае верхнего клапана, прорезь — у нижнего. Закрытый торец — одна стенка `right`/`left` на боку `back`.
- Лепестки ручки (`lidLeaves(o)`, `net.leaves`): контуры в окне крышки, сгибы по краям перемычки (`creases`); у модели — `buildHandle` (`handle-box.js`), поднятые вертикально. Без перемычки (`bridgeMM(o) < 1`) лепестки — отдельные детали (`part`), в каркас не входят.
- Модель открывает торец через `rt.hb` (`scene/renderer.js`, `applyLid`): верхний клапан до 150°, нижний до 90°, клапаны `dust` до 90°, язычок отходит; доля открытия — от `o.lid`.

### Task 1: семейство `handleFold` и лепестки ручки в каркасе

**Files:**
- Modify: `src/app/carriers/fold-rig.js` (`foldFamily`: `if (lt === 'handle') return handleFold;`; новое семейство; лепестки в `buildRig`)

**Interfaces:**
- Produces: `handleFold = { T, roots, hinge }` в стиле `boxFold`:
  - `roots`: панель `bottom`.
  - `hinge`: стенки полосы — 90° (`top` от `back`, `front` от `top`); `glue` — 90° внутрь под дно (как `tab` у `boxFold`: `a: -T, slide: -2 * T`); `dust` — 90° внутрь, складываются первыми (`rank` меньше, чем у клапанов торца); `rightBottom`/`leftBottom` — 90° вверх, затем `rightTop`/`leftTop` — 90° вниз поверх них (позже по `rank`); язычок (`tab` на верхнем клапане) — 90° внутрь, в прорезь; закрытая стенка `right`/`left` — 90°. Смещения `a`/`d` подобрать так, чтобы `foldDrift` ≤ 0,5 мм.
  - Лепестки: если `net.leaves` есть — каркас вырезает их контур из панели `top` (как окно) и вешает каждый лепесток на свой сгиб у перемычки, угол — от 0 (лежит в крышке) до 90° (стоит, как у модели) в конце сборки. Печать лепестка — с грани лепестка (`HANDLE_KEYS`), оборотом наружу, как у модели (см. `buildHandle` и комментарий README про «оборот картона» у поднятой ручки).

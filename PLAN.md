# План доработок Box Studio 3D

Что осталось сделать из того, что мы обсуждали. Задачи идут по порядку: первая — ближайшая. Сделанное отмечено в конце.

## Куда идёт продукт

Box Studio 3D станет веб-сервисом для графического дизайна на упаковке. Это не CAD: профессиональные конструкторы останутся в SolidWorks, ArtiosCAD и т. п., мы их не заменяем. Что даём пользователю:

- пробовать и делать графический дизайн на упаковке в 3D;
- настраивать размеры и параметры упаковки;
- загружать параметрические модели и готовые 3D-модели и наносить на них дизайн;
- утверждать дизайн с заказчиком;
- размещать мокапы в портфолио и встраивать их в свои сайты;
- выгружать макеты дизайна (развёртки, картинки, файлы для типографии);
- работать через ИИ-агента: встроенного в редактор и удалённого, через CLI и MCP.

## 1. Четырёхклапанный гофрокороб (FEFCO 0201)

Сейчас гофрокороб раскладывается крестом, как обычная коробка. Настоящий устроен так:

- четыре стенки идут лентой и склеены боковым клеевым клапаном;
- сверху и снизу у стенок по клапану: длинные сходятся посередине, короткие под ними.

Нужен новый тип крышки «четырёхклапанный». Это изменение и в 3D: клапаны открываются, как крышка. Плюс развёртка, заготовка в `PRESETS` (`core/constants.js`) и ветки по типу крышки (`carriers/box.js`, `core/model.js`, `ui/model-panel.js`).

## 2. Экспорт для технолога

Файл SVG, позже DXF и PDF, который технолог откроет в ArtiosCAD, Impact и т. п.:

- слои по общепринятым цветам: рез, биговка, перфорация, клей, вылет;
- габариты заготовки и размеры панелей;
- внутренние и внешние размеры собранной коробки, толщина картона;
- подпись стиля, например «FEFCO 0427»;
- для коробки с ручкой — отдельный файл печати оборота (зеркально), сейчас оборот нарисован на том же листе рядом с подложкой.

Делать, когда раскладки устоятся (после пункта 1).

## 3. Мелочи, замеченные по ходу

- Рукав-переноска: наклейка, поставленная на грань рукава, ложится на крышку тортницы, а не на ленту (наклейки тортницы рассчитаны только на крышку). Окно внизу пока только внутри одной панели: через сгиб на дно или на скат не переходит.

- Коробка с ручкой: предупреждать в панели модели, если лепесток не помещается в свою половину окна. Тогда вырез выходит за окно, и это может быть неожиданно.
- Стакан: добавить на развёртку круг дна отдельной деталью.
- Угловые клапаны лотка-креста сейчас клеевые. Если технологи чаще делают замковые углы без клея, добавить выбор.
- Прозрачная ПЭТ-крышка коробки «крышка-дно» раскладывается тем же крестом с клеевыми клапанами. Сверить с технологом, так ли её делают.
- Окно через переднее ребро плоской откидной крышки на развёртке — два отдельных выреза (в крышке и в стенке), потому что передний край крышки свободный. Проверить, что пользователей это не удивляет.

## 4. Веб-сервис и модели (крупные направления, порядок ещё не решён)

- **Серверная часть.** Аккаунты, проекты на сервере, библиотека картинок и моделей пользователя.
- **Согласование с заказчиком.** Ссылка на мокап, комментарии прямо на модели, кнопка «Согласовать», история версий.
- **Портфолио и встраивание.** Публичная страница мокапа и код для вставки 3D-просмотра на свой сайт (лёгкий просмотрщик без редактора).
- **Параметрические модели из картона и бумаги.** Общий движок «панели и сгибы»: изделие описано данными (панели, размеры, сгибы, клей, лицевая сторона), а 3D, грани для дизайна, развёртка и поля настроек строятся из описания. Начать с лотка-креста: его 3D и развёртка должны совпасть с нынешними байт в байт. Потом переносить остальные изделия по одному. Формованный пластик и плёнку оставить отдельным кодом.
- **Параметрические формы из пластика.** Небольшой набор операций вместо CAD-ядра: вращение профиля (тортницы, стаканы, банки), вытягивание скруглённого прямоугольника с уклоном (лотки, ланч-боксы, блистеры), фланец, толщина стенки, скругления.
- **Загрузка готовых 3D-моделей** (GLB, OBJ, STL, выгруженных из SolidWorks и т. п.). Пользователь задаёт материал и цвет и отмечает, куда наносится дизайн; для формованных изделий это в основном наклейки. Модель хранится в проекте, а не в редакторе.
- **Выгрузка макетов.** PDF для типографии с вылетами и раздельными слоями отделки (фольга, УФ-лак); выгрузка 3D для AR (GLB/USDZ).
- **Работа через ИИ-агента.** Всё, что делает пользователь, доступно как команды над данными проекта (создать объект, задать размеры, добавить слой или наклейку, выгрузить развёртку или картинку). На этих командах строятся три входа: встроенный агент в редакторе (чат: «сделай коробку 200×150×60 в крафте с логотипом на крышке»), CLI и MCP-сервер для внешних агентов. Для удалённой работы нужна отрисовка без интерфейса (headless) — картинки, развёртки и превью на сервере. Порядок: сначала слой команд и headless-выгрузка, потом MCP и CLI, потом встроенный чат.
- Режим разработки без сборки: открывать `src/index.html` через локальный сервер и обновлять страницу без `npm run build`.

## Как проверять

- `npm run check`, перед пушем в основную ветку `PW_CHROMIUM=/opt/pw-browsers/chromium npm run prepush` (CI нет, тесты только локально; их немного: открытие, все заготовки, проект, выгрузка).
- Переделки, которые не должны менять вид, сверять снимками: `node test/snapshots.mjs <папка>` на старой и новой сборке, затем `--compare`. 3D всех заготовок должен совпасть байт в байт, меняться должны только развёртки тех изделий, которые трогали.
- Развёртку смотреть глазами: шаблон SVG (рез, биговки, подписи) и PNG с дизайном. Чтобы проверить, что рисунок граней лёг правильной стороной, подпишите каждую грань текстом со стрелкой «↑» и сравните с 3D.

## Сделано

- Модули ES, контекстное меню, группы с раскладкой в ряд, слои через рёбра, кольцевые грани (PR 3–7).
- Бумажный пакет с ручками (новый тип объекта).
- Наклейки: фото-наклейка, картинка на фон, выбор картинок для наклеек из библиотеки, перетаскивание из библиотеки на наклейку.
- Рукав с ручкой по обычной конструкции, лоток-крест, ручка из крышки, рукав-переноска для тортницы (PR 8).
- Мейлер по FEFCO 0427 (коробки с крышкой «заправляется внутрь»): цельная вырубка без клея, двойные передняя и боковые стенки с замками в прорези дна, ушки на концах передней и задней стенок, двойной передний клапан крышки с пылевыми ушками. 3D прежний, упрощённый. Раскладка развёрток — версия 3 (`NET_V` в `carriers/box-net.js`); проекты с загруженным макетом развёртки держат прежнюю.
- Внутренние полосы двойных стенок у коробок с откидной крышкой: у передней и боковых стенок (задняя остаётся одинарной, на ней крышка).

Стоит сверить с технологом: пылевые ушки мейлера сейчас на концах переднего клапана крышки (так было и в 3D); бывает, что их делают на боковых краях самой крышки.
